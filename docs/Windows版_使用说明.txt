  水稻穗粒数计数工具 v2.0（EOPT + 遮挡校正版）
  2026-09-26

【和 v1.0 的区别（重要）】
v1.0 用的是检测参数 conf=0.5 / iou=0.8、且没有遮挡补偿，
  实测单穗误差 MAPE 19.6%（密穗普遍低估 20~40%）；
v2.0 做了两处改进，并用 32 株人工数粒真值标定、嵌套留一交叉验证：
  ① 检测参数改为 conf=0.5 / iou=0.5（消除同一粒被重复计框）
  ② 逐穗遮挡校正：用图像特征（框面积中位数 / 谷粒像素占比 /
     框覆盖重数等）回归出每穗的遮挡系数，密穗自动补回被遮住的粒
  ③ 自适应开关：检出<50 粒的穗判为"无明显遮挡"，直接用检测数
→ 实测 MAPE 由 19.6% 降到 10.3%（密穗段 22.1% → 13.8%）

【这是什么】
免安装小程序：给它一个装穗扫描图的文件夹，自动
① 分穗（每张图找出每株穗）
② 逐穗检测谷粒 + 遮挡校正
③ 输出 CSV 统计表 + 整图标注 + 单穗框图 + 逐粒编号图

【怎么用（普通电脑直接双击）】
1. 把 exe 拷到任意 Windows 电脑（Win10/11 64位）
   ——不需要装 Python，不需要联网，模型和标定参数已内置
2. 双击打开程序
3. 【浏览...】选图片文件夹（支持 jpg/png/bmp/tif）
4. 【浏览...】选结果保存位置（默认在图片文件夹下建"计数结果"）
5. 置信度保持默认 0.5（已标定，建议不要改）
6. 点【开始计数】→ 等进度条跑完
7. 结果文件夹里：
   - 穗粒数统计.csv          ← 主结果：校正后粒数（Excel/WPS 直接打开）
   - 穗粒数统计_原始检测.csv  ← 对照：未校正的原始检测数
   - labeled\                ← 整图标注（彩框=每株穗，P1=XX粒）
   - per_panicle\            ← 单穗检测框图（绿框=算法计入的每一粒）
   - per_panicle_numbered\   ← 【逐粒编号图】每粒一个框+序号（自上而下、
                               自左而右），顶栏写"检测N / 校正后M"，
                               方便你逐粒核对：N=实际框数，M=上报粒数
                               绿字=未校正；橙字=该穗做过遮挡校正

【命令行批量（可选）】
  panicle-grain-counter-v2-windows-x64.exe --cli "输入图片文件夹" "输出文件夹" 0.5
  日志写输出文件夹\cli_log.txt，跑完自动退出

【注意事项】
- 图片要黑底、穗清晰完整、谷粒黄色（本工具按此成像条件调过）
- 图里有尺子没关系，会自动排除
- 极度紧密（整穗>140 粒且严重遮挡）的穗仍可能低估 10~15%，
  这类穗建议看 per_panicle_numbered\ 人工复核
- 速度：每穗约 2 秒（纯 CPU），18 张图约 1~2 分钟

【原理（写给要写论文的你）】
- 分穗：HSV 颜色掩码 + 闭运算连通域 + 双规则排除尺子
- 检测：YOLOv8 单类谷粒检测（GrainNuber.onnx，letterbox 保比例 + NMS
  conf=0.5 iou=0.5）
- 校正：ridge 回归 N_true ≈ f(n_det, 框面积中位数, 谷粒像素占比,
  框覆盖重数)，标定于 32 株人工真值穗（疏/中/密分层抽样）
- 模型来源：EOPT（Sun J, et al. Plant Phenomics 2024, 6:0213,
  PMID 39091338；github.com/SUNJHZAU/EOPT）
- 标定方法与验证细节见：
  J:\claw\水稻穗粒数计数_2026-09-12\EOPT版_v2_校正版\README.md
